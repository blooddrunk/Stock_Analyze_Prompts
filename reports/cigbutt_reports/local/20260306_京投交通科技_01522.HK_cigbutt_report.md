## 五、支柱一：存量资产垫评估

### 5.1 T0 计算

> 主计算采用 H1 2025；对比参考采用 FY2024。金额单位为 `千港元`，每股 NAV 为 `港元/股`。

**主计算（H1 2025）**：
```text
现金池 = 现金及现金等价物 678,222（H1 2025）
       − 受限制银行存款 38,033（H1 2025）
       + 短期理财 0
       + 定期存款 0
       = 640,189

T0 = 现金池 640,189 − 总负债 1,837,422 = -1,197,233
T0_NAV = -1,197,233 / 2,097,146,727 = -0.571
当前股价 = 0.330
判定：T0_NAV < 股价 -> T0不达标
```

**对比参考（FY2024）**：
```text
T0(FY2024) = 725,439 − 1,892,173 = -1,166,734
T0_NAV(FY2024) = -1,166,734 / 2,097,146,727 = -0.556
```

### 5.2 T1 计算

**主计算（H1 2025）**：
```text
有息负债 = 银行借款 129,393 + 其他借款 216,031 + 租赁负债 30,705 = 376,129
现金池 = 640,189
T1 = 640,189 − 376,129 = 264,060
T1_NAV = 264,060 / 2,097,146,727 = 0.126
判定：T1_NAV < 股价 0.330 -> T1不达标
T1_NAV / 股价 = 0.126 / 0.330 = 0.38x
```

**对比参考（FY2024）**：
```text
T1(FY2024) = 725,439 − 423,299 = 302,140
T1_NAV(FY2024) = 302,140 / 2,097,146,727 = 0.144
T1_NAV / 股价 = 0.144 / 0.330 = 0.44x
```

> 趋势分析：T1 安全边际从 FY2024 的 0.44x 收窄至 H1 2025 的 0.38x，主因是可自由支配现金减少，而借款虽下降但仍维持在 3.76 亿 HKD 水平。

### 5.3 T2 计算

> 本报告主口径对合同资产采用 `0.5x` 折扣，原因是其回收依赖项目验收与保留款释放；这比把合同资产视同应收账款更保守。

**主计算（H1 2025）**：
```text
T2 = 现金 640,189 × 1.0
   + 应收账款及票据净额 1,036,781 × 0.85
   + 存货 541,466 × 0.60
   + 其他流动资产 [合同资产 848,356 + 其他应收净额 136,361 + 可回收增值税 28,392] × 0.50
   − 总负债 1,837,422

   = 640,189
   + 881,264
   + 324,880
   + 506,554
   − 1,837,422
   = 515,465

T2_NAV = 515,465 / 2,097,146,727 = 0.246
判定：T2_NAV < 股价 0.330 -> T2不达标
```

**对比参考（FY2024）**：
```text
T2(FY2024) = 725,439
           + 1,213,638 × 0.85
           + 451,136 × 0.60
           + [735,056 + 55,701 + 16,425] × 0.50
           − 1,892,173
           = 539,131

T2_NAV(FY2024) = 539,131 / 2,097,146,727 = 0.257
```

> 趋势分析：T2 安全边际由 FY2024 的 0.257/股 微降至 H1 2025 的 0.246/股。  
> 敏感性说明：若把合同资产按 `0.70x` 而非 `0.50x` 计入，H1 2025 的 T2_NAV 约为 `0.327/股`，接近现价；若按 `0.85x` 计入则约为 `0.387/股`。主结论仍采用 `0.50x` 保守口径。

### 5.4 特殊科目处理

- **受限现金**：H1 2025 受限现金 38.0 百万 HKD，占财务状况表现金 5.61%，已从现金池剔除。
- **合同负债**：80.6 百万 HKD，不纳入现金池。
- **质押资产**：6.0 百万 HKD 应收票据/贸易应收作保理质押；另有附属公司 30% 股权质押给控股股东体系关联方，计入治理/质押风险提示。
- **租赁负债**：30.7 百万 HKD，已并入有息负债。
- **补充口径**：若按“未折扣流动资产−总负债”粗口径，H1 2025 为 1,432.2 百万 HKD，对应 0.683/股，约为现价 2.07x；但该口径高估了合同资产和项目类流动资产的可变现性，因此不作为主结论。
